## Behavior Tags

| Tag             | Definition                        | Typical Tactics                                        |
| --------------- | --------------------------------- | ------------------------------------------------------ |
| **Ambush**      | Strikes from hiding or surprise   | Waits for prey, uses terrain advantage, surprise round |
| **Guardian**    | Protects specific location/object | Doesn't pursue beyond area, fights to death            |
| **Territorial** | Defends claimed area aggressively | Warns first (growls/displays), then attacks            |
| **Neutral**     | Not automatically hostile         | Can be avoided, negotiated with, or befriended         |
| **Hunter**      | Actively stalks prey              | Tracks party, tests weaknesses, strategic              |
| **Scavenger**   | Follows fights, seeks easy prey   | Waits for party to be weakened                         |

## Role Tags
| Tag        | Definition                            | Usage                                      |
| ---------- | ------------------------------------- | ------------------------------------------ |
| **Solo**   | Encounters alone, can handle party    | Boss fights, apex predators, champions     |
| **Leader** | Commands/coordinates group            | 1 leader + 2-6 minions, tactical advantage |
| **Minion** | Never encountered alone               | Always with leader or in groups            |
| **Pack**   | Always in groups of same type         | 2-8 creatures, coordinated tactics         |
| **Boss**   | Major solo encounter, multiple phases | Campaign milestone, lair actions possible  |
